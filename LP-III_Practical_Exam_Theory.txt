A1. Fibonacci Series and Computational Steps
----------------------------------------------------------------------------------------

Title: Generate Fibonacci Numbers and Determine the Number of Computational Steps
Required.

Objective:
  * To generate Fibonacci numbers using an algorithm.
  * To understand recursive and iterative approaches.
  * To calculate the number of computational steps and analyze time complexity.

Theory:

The Fibonacci series is a sequence in which every number is the sum of the previous two
numbers. The series starts with: 0, 1, 1, 2, 3, 5, 8, 13, 21, ...

Recurrence:
      F(n) = F(n-1) + F(n-2)
Base conditions:
      F(0) = 0,  F(1) = 1

There are two common approaches:

1. Recursive approach
  * A function calls itself to calculate the previous two Fibonacci numbers.
  * It repeats calculations for the same values.
  * It has exponential time complexity.

2. Iterative approach
  * Uses a loop to calculate the next Fibonacci number.
  * Stores only the previous two values.
  * It is more efficient than recursion.

Algorithm (Iterative):
  1. Start.
  2. Read the number of terms n.
  3. Initialize a = 0, b = 1.
  4. Print a and b when applicable.
  5. Calculate c = a + b.
  6. Update a = b and b = c.
  7. Repeat until n terms are generated.
  8. Count the computational steps.
  9. Stop.

Important points:
  +------------------+-----------------+------------------+
  | Approach         | Time complexity | Space complexity |
  +------------------+-----------------+------------------+
  | Recursive        | O(2^n)          | O(n)             |
  | Iterative        | O(n)            | O(1)             |
  | DP / Memoization | O(n)            | O(n)             |
  +------------------+-----------------+------------------+

  * Recursion uses a function call stack.
  * Iteration avoids repeated calculations.
  * Dynamic programming stores previously calculated results.
  * Computational steps are the basic operations performed by an algorithm.

Conclusion: Thus, we successfully generated the Fibonacci series and analyzed its
computational steps. We observed that the iterative approach is more efficient than the
simple recursive approach.

A2. Job Sequencing with Deadlines
----------------------------------------------------------------------------------------

Title: Implement a Greedy Algorithm for the Job Sequencing Problem with Deadlines.

Objective:
  * To implement the Job Sequencing problem using the Greedy method.
  * To maximize total profit by scheduling jobs before their deadlines.
  * To understand the working of greedy algorithms.

Theory:

Job Sequencing is a scheduling problem in which every job has: (1) Job ID, (2) Deadline,
(3) Profit. Each job requires one unit of time, and profit is earned only when the job
is completed before or on its deadline. The objective is to schedule jobs so that the
maximum possible profit is obtained.

Greedy approach: Select the job having the highest profit first and schedule it in the
latest available time slot before its deadline.

Example:
  +-----+----------+--------+
  | Job | Deadline | Profit |
  +-----+----------+--------+
  | J1  | 2        | 100    |
  | J2  | 1        | 50     |
  | J3  | 2        | 10     |
  | J4  | 1        | 20     |
  | J5  | 3        | 30     |
  +-----+----------+--------+

Sort jobs by decreasing profit: J1 -> J2 -> J5 -> J4 -> J3

One optimal schedule:
  * Slot 1: J2
  * Slot 2: J1
  * Slot 3: J5

Total profit = 50 + 100 + 30 = 180.

Algorithm:
  1. Start.
  2. Read the number of jobs.
  3. Enter job ID, deadline and profit.
  4. Sort all jobs in descending order of profit.
  5. Find the maximum deadline.
  6. Create empty time slots.
  7. For each job, check for an available slot from its deadline backwards.
  8. If an empty slot is found, schedule the job.
  9. Calculate total profit.
  10. Display the scheduled jobs and maximum profit.
  11. Stop.

Important points:
  * Technique: Greedy Algorithm.
  * Objective: Maximize profit.
  * Jobs are sorted by decreasing profit.
  * Each job takes one unit of time.
  * A job must be completed before or on its deadline.
  * Time complexity with simple slot searching: O(n log n + nD), where D is the maximum
      deadline.
  * Space complexity: O(D), excluding input storage.

Conclusion: Thus, we implemented Job Sequencing using the Greedy method and obtained an
optimal job schedule that maximizes the total profit under the given deadlines.

A3. Fractional Knapsack Problem
----------------------------------------------------------------------------------------

Title: Design and Implement a Greedy Algorithm for the Fractional Knapsack Problem.

Objective:
  * To implement the Fractional Knapsack problem using the Greedy method.
  * To maximize the total value within the given capacity.
  * To understand the importance of the value-to-weight ratio.

Theory:

The Knapsack problem involves selecting items to maximize total profit without exceeding
the capacity of a bag. Each item has a Weight (W) and a Value (V). In Fractional
Knapsack, we are allowed to take a fraction of an item. The greedy strategy selects
items according to their value-to-weight ratio.

      Ratio = Value / Weight

The item having the highest ratio is selected first.

Example: Knapsack capacity = 50 kg.
  +------+-------+--------+-------+
  | Item | Value | Weight | Ratio |
  +------+-------+--------+-------+
  | I1   | 60    | 10     | 6     |
  | I2   | 100   | 20     | 5     |
  | I3   | 120   | 30     | 4     |
  +------+-------+--------+-------+

Selection:
  * Take I1 completely = 60.
  * Take I2 completely = 100.
  * Remaining capacity = 20 kg.
  * Take 20/30 fraction of I3 = 80.

      Total profit = 60 + 100 + 80 = 240

Algorithm:
  1. Start.
  2. Read the number of items and knapsack capacity.
  3. Enter weight and value of each item.
  4. Calculate value/weight ratio.
  5. Sort items in descending order of ratio.
  6. Select the item with the highest ratio.
  7. If the complete item fits, take it.
  8. Otherwise, take the required fraction.
  9. Update remaining capacity.
  10. Repeat until capacity becomes zero.
  11. Display maximum profit.
  12. Stop.

Important points:
  * Technique: Greedy Algorithm.
  * Items can be divided into fractions.
  * Selection is based on maximum value/weight ratio.
  * Sorting complexity: O(n log n). Overall time complexity: O(n log n).
  * Fractional Knapsack gives an optimal solution using the greedy method.

Conclusion: Thus, we successfully implemented the Fractional Knapsack problem using the
Greedy approach and maximized the total profit within the given capacity.

A4. 0/1 Knapsack Problem
----------------------------------------------------------------------------------------

Title: Implement the 0/1 Knapsack Problem Using Dynamic Programming or Branch and Bound.

Objective:
  * To solve the 0/1 Knapsack problem.
  * To maximize profit without exceeding the capacity.
  * To understand Dynamic Programming or Branch and Bound techniques.

Theory:

The 0/1 Knapsack problem is an optimization problem in which we select items to maximize
total value without exceeding the given capacity. Unlike Fractional Knapsack, an item
cannot be divided. Every item has only two possibilities: 1 = select the complete item,
0 = do not select the item.

Dynamic Programming approach: Construct a two-dimensional DP table where rows represent
items, columns represent knapsack capacities, and each cell stores the maximum profit
possible.

Recurrence relation:
      DP[i][w] = DP[i-1][w],   if wt(i) > w
      DP[i][w] = max( DP[i-1][w],  val(i) + DP[i-1][w - wt(i)] ),   if wt(i) <= w
Base conditions:
      DP[0][w] = 0   and   DP[i][0] = 0

Algorithm (Dynamic Programming):
  1. Start.
  2. Read the number of items and capacity.
  3. Enter weights and values.
  4. Create a DP table of size (n+1) x (W+1).
  5. Initialize the first row and column with zero.
  6. For every item and capacity:
      - If item weight exceeds capacity, copy the previous value.
      - Otherwise, calculate the maximum of including and excluding the item.
  7. Store the result in the DP table.
  8. Display DP[n][W].
  9. Stop.

Branch and Bound approach: Explores possible solutions using a state-space tree.
  * Branch: Divide the problem into include and exclude decisions.
  * Bound: Calculate an upper bound on the possible profit.
  * Prune: Discard branches that cannot improve the current best solution.

Important points:
  +-----------------+--------------------------+---------------------+
  | Feature         | 0/1 Knapsack             | Fractional Knapsack |
  +-----------------+--------------------------+---------------------+
  | Item division   | Not allowed              | Allowed             |
  | Main technique  | DP / Branch and Bound    | Greedy              |
  | Selection       | Complete item or nothing | Any fraction        |
  | Greedy optimal? | Not always               | Yes                 |
  +-----------------+--------------------------+---------------------+

  * DP time complexity: O(nW). DP space complexity: O(nW).
  * It is called pseudo-polynomial time because complexity depends on the numerical
      capacity W.

Conclusion: Thus, we implemented the 0/1 Knapsack problem using Dynamic Programming or
Branch and Bound to obtain the maximum possible profit without exceeding the capacity.

A5. Binomial Coefficients Using Dynamic Programming
----------------------------------------------------------------------------------------

Title: Calculate Binomial Coefficients Using Dynamic Programming.

Objective:
  * To calculate binomial coefficients using Dynamic Programming.
  * To understand Pascal's Triangle.
  * To reduce repeated calculations using previously computed results.

Theory:

A binomial coefficient represents the number of ways to select r objects from n objects.
      nCr = n! / ( r! (n-r)! )
For example: 5C2 = 5! / (2! 3!) = 10

Instead of calculating factorials repeatedly, we use Dynamic Programming.

Recurrence relation:
      C(n, r) = C(n-1, r-1) + C(n-1, r)
Base conditions:
      C(n, 0) = 1   and   C(n, n) = 1

These values form Pascal's Triangle.

Example - Pascal's Triangle:
            1
          1   1
        1   2   1
      1   3   3   1
    1   4   6   4   1
5C2 = 10

Algorithm:
  1. Start.
  2. Read n and r.
  3. Create a DP table.
  4. Set C[i][0] = 1.
  5. Set C[i][i] = 1.
  6. For each remaining position, calculate C[i][j] = C[i-1][j-1] + C[i-1][j].
  7. Display C[n][r].
  8. Stop.

Important points:
  * Technique: Dynamic Programming.
  * Pascal's Triangle is used.
  * Each value depends on two values in the previous row.
  * Time complexity: O(nr) when computing only up to r.
  * Space complexity: O(nr) for the full DP table. One-dimensional DP can reduce space
      to O(r).

Conclusion: Thus, we successfully calculated binomial coefficients using Dynamic
Programming and reduced repeated computations using previously stored results.

A6. 8-Queens Problem Using Backtracking
----------------------------------------------------------------------------------------

Title: Solve the 8-Queens Problem Using Backtracking.

Objective:
  * To place eight queens on an 8x8 chessboard.
  * To ensure that no two queens attack each other.
  * To understand the Backtracking technique.

Theory:

The 8-Queens problem is a classical problem in which eight queens must be placed on an
8x8 chessboard. A queen can attack another queen if they are in the same (1) Row, (2)
Column or (3) Diagonal. Therefore, no two queens should share any of these positions.

Backtracking: An algorithmic technique that builds a solution step by step. If a
selected position violates the constraints, the algorithm removes that choice and tries
another position.

Algorithm:
  1. Start.
  2. Initialize an empty 8x8 chessboard.
  3. Place the first queen at the given position.
  4. Move to the next row.
  5. Check every column for a safe position.
  6. If a safe position is found, place a queen.
  7. Move to the next row.
  8. If no safe position exists, remove the previously placed queen.
  9. Try the next available position.
  10. Continue until all eight queens are placed.
  11. Display the solution.
  12. Stop.

Safety conditions: A position is safe if:
  * No queen exists in the same column.
  * No queen exists in the upper-left diagonal.
  * No queen exists in the upper-right diagonal.
Because we place one queen per row, checking the same row is unnecessary.

Important points:
  * Technique: Backtracking. Board size: 8x8. Total queens: 8.
  * One queen per row and column.
  * There are 92 distinct solutions if rotations and reflections are counted separately.
  * Common upper-bound time complexity for the row-wise backtracking approach: O(N!).
  * Space complexity: O(N^2) for the board.

Conclusion: Thus, we successfully solved the 8-Queens problem using Backtracking by
placing eight queens without violating the attacking conditions.

B1. Uber Fare Prediction Using Regression
----------------------------------------------------------------------------------------

Title: Uber Fare Prediction Using Linear Regression and Random Forest Regression.

Objective:
  * To predict Uber fare prices using Machine Learning.
  * To perform data preprocessing and detect outliers.
  * To perform correlation analysis.
  * To implement Linear Regression and Random Forest Regression.
  * To compare both models using R2 and RMSE.

Theory:

Regression is a supervised Machine Learning technique used to predict continuous
numerical values. In this practical, we predict Uber fare prices based on features such
as pickup location, drop-off location, passenger count, distance and other numerical
features.

1. Data Preprocessing: Cleaning and transforming raw data into a suitable format.
  * Remove duplicate records.
  * Handle missing values.
  * Convert data types.
  * Remove unnecessary columns.
  * Handle outliers.

2. Outlier Detection: Outliers are data points significantly different from other
observations. The IQR method is commonly used.
      IQR = Q3 - Q1
      Lower limit = Q1 - 1.5 x IQR
      Upper limit = Q3 + 1.5 x IQR
Values outside these limits are potential outliers.

3. Correlation Analysis: Correlation measures the relationship between two variables.
Pearson correlation coefficient: -1 <= r <= 1.
  * +1: Perfect positive correlation.
  * -1: Perfect negative correlation.
  * 0: No linear correlation.
A heatmap can be used to visualize correlation.

4. Linear Regression: Predicts a continuous value by establishing a linear relationship
between independent and dependent variables.
      Y = mX + c
Where Y = predicted value, X = independent variable, m = slope, c = intercept.

5. Random Forest Regression: An ensemble learning algorithm that combines multiple
decision trees. Each tree generates a prediction, and the final output is generally the
average of all tree predictions.
  * Handles nonlinear relationships.
  * Reduces overfitting compared with a single decision tree in many cases.
  * Works with multiple features.

Algorithm:
  1. Start.
  2. Import required libraries.
  3. Load Uber fare dataset using Pandas.
  4. Check missing values and duplicate records.
  5. Perform data cleaning and preprocessing.
  6. Detect and handle outliers using IQR.
  7. Perform correlation analysis.
  8. Select independent and dependent variables.
  9. Split dataset into training and testing sets.
  10. Train Linear Regression model.
  11. Train Random Forest Regression model.
  12. Predict fare prices.
  13. Calculate R2 and RMSE for both models.
  14. Compare model performance.
  15. Stop.

Important formulas:

R2 Score (Coefficient of Determination) - how well the model explains variation in the
target variable:
      R2 = 1 - [ sum (y - y_pred)^2 ] / [ sum (y - y_mean)^2 ]

RMSE (Root Mean Squared Error) - average magnitude of errors, larger errors penalized
more:
      RMSE = sqrt( (1/n) x sum (y - y_pred)^2 )

Important points:
  * Type: Supervised Learning. Task: Regression. Target: Uber fare.
  * Linear Regression: linear relationship. Random Forest: ensemble of decision trees.
  * Higher R2 generally indicates better fit.
  * Lower RMSE indicates better prediction accuracy.
  * RMSE is expressed in the same units as the target variable.

Conclusion: Thus, we successfully predicted Uber fares using Linear Regression and
Random Forest Regression. We compared both models using R2 and RMSE to identify the
better-performing model.

      TF-IDF = TF x IDF

2. K-Nearest Neighbors (KNN): Classifies a new data point based on its nearest K

      Euclidean distance d = sqrt( sum (x_i - y_i)^2 )

3. Support Vector Machine (SVM): A supervised learning algorithm for classification and
regression. It finds an optimal hyperplane that separates different classes.
  * Hyperplane: Decision boundary between classes.
  * Support vectors: Data points closest to the hyperplane.
  * Margin: Distance between the hyperplane and nearest support vectors.
SVM tries to maximize the margin between classes.

Algorithm:
  1. Start.
  2. Import required libraries.
  3. Load the email dataset.
  4. Check missing values and clean the text.
  5. Convert email text into numerical features using TF-IDF.

  10. Calculate accuracy and other evaluation metrics.
  11. Compare both classifiers.
  12. Stop.

Important points:
  +----------------+-------------------+--------------------+
  | Feature        | KNN               | SVM                |
  +----------------+-------------------+--------------------+
  | Type           | Supervised        | Supervised         |
  | Technique      | Instance-based    | Margin-based       |
  | Working        | Nearest neighbors | Optimal hyperplane |
  | Main parameter | K                 | C, Kernel          |
  | Prediction     | Distance-based    | Decision boundary  |
  +----------------+-------------------+--------------------+

Advantages of KNN: Simple to implement; no complex training process; easy to understand.
Advantages of SVM: Effective in high-dimensional feature spaces; works well with sparse
text features; supports different kernels.

Evaluation metrics:
  * Accuracy: Overall correct predictions.
  * Precision: How many predicted spam emails are actually spam.
  * Recall: How many actual spam emails are correctly identified.
  * F1-score: Harmonic mean of precision and recall.
      Accuracy = (TP + TN) / (TP + TN + FP + FN)

Conclusion: Thus, we successfully classified emails into Spam and Ham categories using
KNN and SVM. We compared the performance of both classifiers using evaluation metrics.

B5. Customer Segmentation Using K-Means and Hierarchical Clustering
----------------------------------------------------------------------------------------

Title: Customer Segmentation Using K-Means or Hierarchical Clustering.

Objective:
  * To group customers based on similar characteristics.
  * To implement K-Means or Hierarchical Clustering.
  * To determine the optimal number of clusters using the Elbow Method.

Theory:

Customer segmentation divides customers into groups based on their characteristics and
purchasing behavior. It is an unsupervised Machine Learning technique because the
dataset has no predefined target labels. The dataset is sales_data_sample.csv. Customers
can be grouped on sales, purchase frequency, order value and spending patterns.

1. K-Means Clustering: Divides data into K clusters; each cluster has a centroid
representing its center. Working:
  1. Select the number of clusters K.
  2. Initialize K centroids.
  3. Calculate the distance between data points and centroids.
  4. Assign every data point to the nearest centroid.
  5. Recalculate the centroids.
  6. Repeat until the centroids stop changing significantly.

2. Elbow Method: Determines the optimal number of clusters using Within-Cluster Sum of
Squares (WCSS).
      WCSS = sum over i=1..K of sum over x in Ci of (x - mean_i)^2
Where K = number of clusters, Ci = cluster, mean_i = cluster centroid. As K increases,
WCSS generally decreases. Plot K against WCSS and identify the elbow point where the
reduction starts slowing down.

3. Hierarchical Clustering: Creates a hierarchy of clusters.
  * Agglomerative: Starts with individual points and repeatedly merges the closest
      clusters.
  * Divisive: Starts with one cluster and repeatedly divides it into smaller clusters.
A dendrogram is used to visualize the hierarchical relationships.

Algorithm (K-Means):
  1. Start.
  2. Import required libraries.
  3. Load sales_data_sample.csv.
  4. Perform data cleaning.
  5. Select relevant numerical features.
  6. Normalize or standardize the data.
  7. Apply the Elbow Method.
  8. Determine the optimal K.
  9. Initialize K-Means with the selected K.
  10. Fit the clustering model.
  11. Assign cluster labels to customers.
  12. Visualize the clusters.
  13. Stop.

Important points:
  +-------------------------------+----------------------------------+
  | K-Means                       | Hierarchical                     |
  +-------------------------------+----------------------------------+
  | Partitional clustering        | Hierarchical clustering          |
  | Requires K beforehand         | Does not require K initially     |
  | Uses centroids                | Uses distance between clusters   |
  | Elbow Method                  | Dendrogram                       |
  | Efficient for larger datasets | Can be computationally expensive |
  +-------------------------------+----------------------------------+

  * Type: Unsupervised Learning.
  * K-Means commonly uses Euclidean distance.
  * Centroid is the mean of points in a cluster.
  * Scaling is important because clustering uses distances.
  * WCSS measures within-cluster variation.

Theory:

Solidity provides different data structures for storing and managing information on the
blockchain. In this practical, structures and arrays store student information.

1. Structure (struct): A user-defined data type that groups multiple variables of
different data types into a single unit. A student structure may contain roll number,
student name and marks.
    struct Student {
        uint rollNo;
        string name;
        uint marks;
    }

2. Array: A collection of elements of the same data type. Solidity supports fixed-size
and dynamic arrays. Example (dynamic array of Student structures):
    Student[] public students;

3. Fallback Function: A special function executed when a call does not match any
existing function, or the call contains data that does not match a known function
selector. It is declared using the fallback() keyword.
    fallback() external payable {
        // Executes for unmatched calls
    }
Important: A separate receive() function handles plain Ether transfers with empty
calldata when it is defined. The fallback function handles unmatched calls and may also
receive Ether if declared payable.

4. Gas and Transaction Fees: Gas is the computational unit required to execute smart
contract operations. Operations such as storing student details consume gas. More
complex operations generally require more gas.
      Fee = Gas Used x Gas Price
